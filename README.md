# 悦读相伴 (V3) - 数字人教育干预平台

悦读相伴是一个集 3D 数字人交互、儿童读写能力干预、家长报告分析与专业咨询为一体的教育平台。本版本采用了更阳光清新的设计语言，并全面集成了 3D 老虎“小悦”作为数字伴学伙伴。

## 🌟 核心特性

- **3D 智能数字人**: 具名“小悦”的白老虎伙伴，具备呼吸、眨眼、晃动等多种状态。
- **全场景覆盖**: 包含儿童端（答题训练）、家长端（进度洞察）、咨询师端（干预计划）及管理端。
- **现代 UI/UX**: 基于高性能响应式布局，支持全屏拖拽与动态交互。
- **双端架构**: 极简的高速 FastAPI 后端 + 现代 Vue 3 前端。

## 🚀 快速启动指导

### 1. 环境准备
确保你的电脑已安装以下环境：
- **Node.js**: v18.0+ (前端构建)
- **Python**: v3.9+ (后端服务)

### 2. 获取代码与依赖安装
```bash
# 克隆仓库
git clone https://github.com/6999-web/CCF.git
cd CCF

# 安装后端依赖
cd backend
pip install -r requirements.txt

# 安装前端依赖
cd ../frontend
npm install
```

### 3. 配置 API Key (可选)
如果需要启用英伟达 AI 聊天功能，请在 `backend/` 目录下新建 `.env.local` 文件，并填入你的 Key：
```env
NVIDIA_API_KEY=你的_NVAPI_KEY
```

### 4. 一键启动 (Windows)
在项目根目录下，双击运行：
- **`start.bat`**：此脚本会自动在 `5051` (后端) 和 `5052` (前端) 端口启动所有服务。

启动后，访问地址：`http://101.33.210.169:5052` (或本地 `http://localhost:5052`)。
